# Happy Birthday, Sukanya ❤️

A personal birthday gift website designed for GitHub Pages.

## Files

- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — photo gallery and secret-message interaction
- `assets/photos/` — put your photographs here

## Add your photographs

1. Copy your photos into `assets/photos/`.
2. Open `script.js`.
3. Find the `const photos = []` section.
4. Add entries like:

```js
const photos = [
  { src: "assets/photos/first.jpg", caption: "The beginning ❤️" },
  { src: "assets/photos/funny.jpg", caption: "That day we couldn't stop laughing." },
];
```

## Personalize it

Search `index.html` for text inside `[square brackets]` and replace those sections with your real inside jokes and any personal details you want to add. The friendship timeline has already been structured around nursery school → Jaya Aunty's gaan-er class → 10+ years apart → meeting again on a bus.

You can also edit the birthday letter and the final secret message.

## GitHub Pages

Create a GitHub repository, upload all files, then:

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

The website is completely static, so it does not need a server.
